Política de Privacidade — SmartCA Lite

Última atualização: 16 de setembro de 2026

Quem somos

O SmartCA Lite é um aplicativo de controle de acesso para portaria, desenvolvido e distribuído pela HojeTi ("nós"). É uma ferramenta profissional usada por porteiros e equipes de portaria de condomínios, empresas e instituições ("o Cliente").

Como o SmartCA Lite trata os dados

O SmartCA Lite não possui servidores próprios da HojeTi que recebam os dados de uso. O aplicativo se conecta exclusivamente ao servidor definido pelo Cliente. Todos os dados capturados no app são enviados somente para esse servidor.
  • O Cliente é o controlador dos dados (define finalidade e é responsável pelos dados pessoais tratados na portaria).
  • A HojeTi é a fornecedora do software; não coleta, não armazena e não tem acesso aos dados de uso trafegados pelo aplicativo.
  • Os dados não são vendidos, alugados nem compartilhados com terceiros pela HojeTi.

Dados que o aplicativo trata

Para funcionar, o app trata os seguintes dados, sempre enviando-os apenas ao servidor do Cliente:

  • Credenciais do operador (porteiro): usuário e senha para entrar no sistema. O token de sessão é guardado de forma cifrada no próprio dispositivo (Keychain no iOS, Keystore no Android).
  • Imagens da câmera: fotos do rosto de pessoas que acessam o local e de placas de veículos, tiradas pelo operador no registro de acesso.
  • Imagens da galeria (opcional): quando o operador escolhe anexar uma foto existente.
  • Dados operacionais da portaria consultados/registrados no servidor do Cliente (pessoas, veículos, movimentações, equipamentos).

O aplicativo não coleta localização, contatos, identificadores de publicidade nem dados de comportamento.

Permissões do dispositivo

  • Câmera: fotografar o rosto de quem entra e a placa dos veículos na portaria.
  • Fotos/galeria: opcionalmente, anexar uma imagem já existente.

As permissões são solicitadas apenas quando necessárias e podem ser revogadas nas configurações do sistema.

Rastreamento e terceiros

O SmartCA Lite não utiliza ferramentas de análise (analytics), publicidade, redes sociais ou rastreamento de terceiros. Não há SDKs de coleta de dados embarcados no app.

Segurança

O token de sessão é armazenado em área cifrada do dispositivo. A comunicação com o servidor do Cliente deve ocorrer por canal seguro (HTTPS), conforme o ambiente do Cliente.

Retenção e direitos dos titulares (LGPD)

A retenção dos dados e o atendimento aos direitos dos titulares (acesso, correção, exclusão, etc.) são de responsabilidade do Cliente (controlador), que os administra em seu próprio servidor. Para exercer direitos sobre dados de uma portaria específica, o titular deve procurar o respectivo Cliente.

Crianças

O SmartCA Lite é uma ferramenta profissional de portaria, não direcionada a crianças.
